# 微信小程序版本

这个目录是独立的小程序工程，功能与 H5 版本对应：

- 用户管理（新增、删除、切换）
- 项目管理（新增、删除）
- 日历打卡（按完成比例高亮）
- 项目汇总 + 每个项目独立月度分布
- 点击月度分布可跳转对应年月
- 本地持久化（`wx.setStorageSync`）

## 运行方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择：`mp-wechat`
4. `AppID` 可先用测试号（或在 `project.config.json` 改成你自己的）
5. 编译运行
